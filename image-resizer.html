Image Resizer vs Image Compressor

An image resizer changes the dimensions of an image, such as its width and height. An image compressor primarily focuses on reducing the file size.

If your requirement is to make an image smaller in terms of file size, you can use the Image Compressor. If you need a specific file size such as 50KB or 100KB, use the Image Resize by KB tool.
